## Project Description
The Cybersecurity Awareness Chatbot is designed to educate users about essential cybersecurity practices. It engages users through interactive conversations, providing information on topics such as password safety, phishing awareness, and safe browsing habits. The chatbot utilizes voice greetings and personalized interactions to enhance user experience and retention of information.

## Features
- Voice greeting to welcome users
- Engaging ASCII art for visual appeal
- Personalized greeting based on user input
- Responses focused on password safety
- Information and tips regarding phishing threats
- Guidance on safe browsing practices
- Input validation to ensure user data integrity
- Coloured console interface for an enhanced user experience

## How to Run
1. Clone or download the repository.
2. Open the solution in Visual Studio 2022.
3. Ensure `greeting.wav` is available in the application output directory (or project root and set to "Copy to Output Directory").
4. Build the project targeting .NET 8.
5. Press Ctrl + F5 to run without debugging.

## Requirements
- Visual Studio 2022
- .NET 8 SDK
- Windows audio support for `SoundPlayer` if using the Windows-only playback path (or ensure a cross-platform fallback is present)
